# 🌌 创意前端实验库 (Creative Front-end Experiments|html_trials)

这个仓库记录了我从“灵光一闪”到“用代码把幻想视觉化”的小尝试。所有的项目均为**纯原生单文件 HTML/CSS/JS**，零第三方依赖，双击即可在浏览器中运行。

从最初的简单意象，到多场景互动，再到遵循天文物理规律的月相演变，这里是我用 Canvas 像素堆砌的一座座小岛。

## 📂 项目目录

### 1. 🏔️ 多场景互动：梦境之旅 (Dream Journey|Triple Dreams)
**文件：`dreamjourney_v2.0.html`**

**旧版（原三重梦境）：`JOURNEY_Multimediaversion.html`**

一次关于“视差与转场”的练习，在梦幻的场景中治愈心灵。包含三个意象场景：
- **月下石洞**：夜空银河与林间小径尽头的倒三角光标。
- **晚霞海岸**：靠在栏杆边看海的人影剪影。
- **极地雪原**：绚烂极光与雪地上的三脚架相机。
*特性：点击倒三角触发点可以无缝淡入淡出切换场景，带有火流星划过的动态特效。*

### 2. 🌙 月相之旅 (Moon Phase Journey)
**文件：`MOONJOURNEY_Multimedia_HB.html`**
跟随半个月的月相演变，从新月走向满月，沿途经过五个不同的场景：
- **新月**：深夜草原银河。
- **蛾眉月**：傍晚粉紫霞光，金星伴月（以实拍图为参照还原了倾斜的极细月牙）。
- **上弦月**：下午浅蓝天空，两直两半圆的塑胶操场与教学楼。
- **渐盈凸月**：小县城夜市，沿街的摊位与升腾的烟火气。
- **满月**：浦东黄浦江畔，巨大的金黄满月与东方明珠等地标剪影。
*特性：支持手势/鼠标滑动翻页，满月后解锁全局导航。每一页有倒三角光标，点击触发弹窗一言*

## 🛠️ 踩坑与技术记录

在这个仓库的构建过程中，我经历了无数次与 AI 的“斗智斗勇”，也留下了许多 Debug记忆：
- **“蹦迪”的天际线**：因为把随机生成的建筑高度写在了渲染循环里，导致浦东的楼群每秒钟都在疯狂上下跳动。
- **“麻花”操场**：画跑道时左右圆弧的方向参数写反，导致两边的半圆拧成了一个蝴蝶结。
- **“糖葫芦”东方明珠**：球体半径计算错误，导致两个球挤在一起。
- **天文级月相**：起初几版的蛾眉月都渲染出了上弦月，最终通过 `arc` 和 `ellipse` 遮罩算法，还原了不同时间的月相与暗部透视。
